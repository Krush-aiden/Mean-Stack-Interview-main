HOW TO READ THIS FILE
---------------------
Original question numbers (Q1-Q110) are kept so you can cross-check with the
old file. Questions are grouped into 3 parts by how deeply you need to know them:

  PART A : KNOW CODE + IMPLEMENTATION   -> be ready to write/live-code it   (53 Qs)
  PART B : HIGH-LEVEL AWARENESS ONLY    -> know what/why/trade-offs         (19 Qs)
  PART C : THEORY + CONCEPTUAL          -> explain clearly, small snippets  (38 Qs)

Inside each part, questions are sorted by importance:

  [***] MUST KNOW     - asked in almost every 2-3 yr interview
  [** ] SHOULD KNOW   - asked frequently
  [*  ] GOOD TO HAVE  - asked occasionally / bonus points

Suggested prep order: A[***] -> C[***] -> A[**] -> B[***] -> C[**] -> rest.
