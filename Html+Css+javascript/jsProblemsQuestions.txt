 SECTION 1 : STRING PROBLEMS
=====================================================================

1. Write a function to check if a given string is a palindrome.
   - Approach 1: Using a for loop
   - Approach 2: Using built-in methods (split, reverse, join)

2. Implement a function to reverse a string without using the built-in reverse() method.

3. Convert the first letter of each word in a sentence to uppercase (Title Case).
   Input:  'krushna chandra mahapatra'
   Output: 'Krushna Chandra Mahapatra'

4. Given a string, write a function to count the occurrences of each character in the string.
   - Also find which characters appear more than once.

5. Find the longest substring without repeating characters.
   Input:  'abcabcbb'
   Output: 3 (substring: 'abc')

6. Check if two strings are anagrams of each other.
   Input:  'listen', 'silent'
   Output: true

7. Write a function to find all permutations of a string.
   Input:  'abc'
   Output: ['abc','acb','bac','bca','cab','cba']

8. Implement a function to compress a string using character counts.
   Input:  'aabcccccaaa'
   Output: 'a2b1c5a3'


=====================================================================
 SECTION 2 : ARRAY PROBLEMS
=====================================================================

9. Given an array of numbers, find the largest and smallest numbers.
   - Approach 1: Using a for loop
   - Approach 2: Using Math.max / Math.min with spread

10. Write a function to find the largest element in a nested array.
    Input:  [[8,4,10],[24,2,44],[5,34]]
    Output: 44

11. Return a new array with only the unique elements (remove duplicates).
    - Approach 1: Using a for loop + includes()
    - Approach 2: Using Set

12. Return only the elements that appear exactly once (pure unique — occurrence count = 1).
    Input:  [1,2,3,2,3,4,4,5,6,6,7]
    Output: [1,5,7]

13. Sort an array of numbers in ascending & descending order.
    - Using Array.sort() with comparator
    - Without using sort (Bubble Sort)

14. Find the second smallest and second largest element in an array.

15. Two Sum — find two numbers in an array that add up to a target. Return their indices.
    Input:  [2,7,11,15], target = 9
    Output: [0,1]

16. Find the intersection and union of two arrays.
    Input:  [1,2,3,4], [3,4,5,6]
    Output: intersection = [3,4], union = [1,2,3,4,5,6]

17. Flatten a deeply nested array without using Array.flat().
    Input:  [1,[2,[3,[4]],5]]
    Output: [1,2,3,4,5]

18. Implement Array.prototype.flat with a configurable depth parameter.
    Input:  [1,[2,[3,[4]]]], depth=2
    Output: [1,2,3,[4]]

19. Group an array of objects by a property.
    Input:  [{name:'A', dept:'IT'}, {name:'B', dept:'HR'}, {name:'C', dept:'IT'}], key='dept'
    Output: { IT: [{...},{...}], HR: [{...}] }

20. Rotate an array by K positions (left or right).
    Input:  [1,2,3,4,5], k=2, direction='right'
    Output: [4,5,1,2,3]

21. Find the maximum sum subarray (Kadane's Algorithm).
    Input:  [-2,1,-3,4,-1,2,1,-5,4]
    Output: 6 (subarray: [4,-1,2,1])

22. Chunk an array into groups of a given size.
    Input:  [1,2,3,4,5], size=2
    Output: [[1,2],[3,4],[5]]

=====================================================================
 TIPS FOR 4+ YRS INTERVIEW
=====================================================================
- Always discuss time & space complexity (Big O) for every solution.
- Mention multiple approaches (brute force → optimized).
- For array/string problems, ask: "Is the input sorted?" "Can there be negatives?"
- For async problems, handle errors properly with try/catch.
- Polyfills are asked in EVERY senior-level JS interview — practice them.
- Be ready to implement on a whiteboard or live code editor (no IDE help).
- Know when to use Map vs Object, Set vs Array for performance.
