1. What is event bubbling and capturing in JavaScript?
Event Bubbling: This is the process where an event starts from the target element and bubbles up to the root of the DOM tree. For example, if you click a button inside a div, the click event first triggers on the button, then on the div, and continues up to the document.

Event Capturing: Also known as "trickling," this is the opposite of bubbling. The event starts from the root and trickles down to the target element. In practice, event capturing is less commonly used than bubbling.

JavaScript events can be handled in either phase, but by default, event listeners are set to handle events during the bubbling phase.

2. How does event propagation work in the DOM?
Event propagation in the DOM occurs in three phases:
Capturing Phase: The event travels from the root to the target element.
Target Phase: The event reaches the target element.
Bubbling Phase: The event bubbles up from the target element back to the root.
Developers can choose to handle events in either the capturing or bubbling phase by specifying a third parameter in addEventListener. Setting it to true listens during the capturing phase, while false (default) listens during the bubbling phase.

3. What are the advantages of using event delegation?
Performance: Reduces the number of event listeners, which can improve performance, especially with many elements.
Dynamic Content: Easily handles events for elements added dynamically after the initial page load.
Simplified Code: Centralizes event handling logic, making the code easier to manage and maintain.

4. How can you prevent event bubbling in JavaScript?
To stop an event from bubbling up the DOM tree, you can use the event.stopPropagation() method within an event handler:

element.addEventListener('click', function(event) {
  event.stopPropagation();
  // Event handling logic
});

5. What is the difference between event delegation and direct event handling?
Event Delegation: Attaches a single event listener to a parent element to manage events for multiple child elements. It leverages event bubbling to handle events efficiently.
Direct Event Handling: Attaches individual event listeners to each element that needs to respond to events. This can lead to more event listeners and potentially slower performance.

6. How do you handle events on dynamically added elements?
Event delegation is ideal for handling events on dynamically added elements. By attaching an event listener to a parent element, you can capture events from child elements added after the initial page load.

7. What is the event.target property in JavaScript?
The event.target property refers to the element that triggered the event. It is useful in event delegation to determine which child element was interacted with:

parentElement.addEventListener('click', function(event) {
  console.log('Clicked element:', event.target);
});

8. How do you use event.stopPropagation() and event.preventDefault()?
event.stopPropagation(): Stops the event from bubbling up the DOM tree.
event.preventDefault(): Prevents the default action associated with the event (e.g., following a link when clicking an <a> tag).

9. What are some common use cases for event delegation?
Handling clicks on a list of items: Instead of attaching a click event to each item, attach it to the list container.
Form validation: Use a single event listener on the form to validate inputs dynamically.
Dynamic content: Manage events for elements added via AJAX or other dynamic methods.
These concepts form the foundation of effective event handling in JavaScript, allowing developers to write efficient, maintainable, and performant code.
